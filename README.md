# MP4 章节信息批量注入工具 (MP4 Chapter Injector)

[![Platform](https://img.shields.io/badge/Platform-Windows-blue.svg)](https://www.microsoft.com/windows)
[![FFmpeg](https://img.shields.io/badge/FFmpeg-Stream%20Copy-green.svg)](https://ffmpeg.org/)
[![GUI](https://img.shields.io/badge/GUI-Tkinter%20Modern-orange.svg)](#三快速使用方法)
[![Version](https://img.shields.io/badge/Version-v1.2.0-brightgreen.svg)](#七关于与联系支持)

**MP4 章节信息批量注入工具** 是一款专为视频创作者、课程录制者和影音爱好者打造的高效工具。能够将指定目录及其多层子目录下的 MP4/M4V/MOV 视频与同名章节文本文件进行批量匹配与章节信息**无损极速注入**。

注入章节后的视频在 **PotPlayer**、**VLC**、**IINA** 等主流播放器中，可直接通过**章节抽屉列表**、**进度条断点标记**或**快捷键**进行直观的选集跳转。

---

## 一、核心特性与亮点

1. **无损极速注入（Stream Copy）**：
   - 基于 FFmpeg `-c copy` 流拷贝技术，元数据直接封包，**完全不重新编解码视频与音频**。
   - 数 GB 的超清大视频只需数秒即可注入完毕，**100% 保持原始画质与音质**。
2. **多层子目录递归搜索与层级保持**：
   - 支持递归深度遍历各级子目录，自动将各子目录内的视频与所在目录下的同名文本精准绑定。
   - 非覆盖注入至 `with_chapters/` 时，**自动镜像源目录的多级子目录结构**，彻底杜绝同名文件覆盖冲突。
3. **原生支持主流双章节格式**：
   - **OGM 标准格式**：`CHAPTER01=...` / `CHAPTER01NAME=...`
   - **简易时间戳格式**：`00:00:00 标题名称`（支持 `HH:MM:SS.mmm`、`HH:MM:SS`、`MM:SS`）
4. **多编码与中文自适应**：
   - 内置智能编码探测引擎，原生适配 UTF-8、UTF-8-BOM、GBK、GB18030、Big5 等中文编码，绝不乱码。
5. **现代高自适应 GUI 界面**：
   - 自动根据显示器屏幕分辨率计算黄金比例并居中显示，彻底解决高分屏/笔记本任务栏遮挡界面的问题。
   - 提供标准**系统顶部菜单栏**（文件/操作/帮助）、**右键快捷菜单**、**一键生成测试样例**与**精致关于 (About) 对话框**。
6. **双运行模式**：
   - 既有易用直观的图形化界面 (GUI)，也提供支持脚本自动化静默运行的命令行界面 (CLI)。

## 二、支持的章节文本格式

文本文件需与视频同名（例如 `01.mp4` 对应 `01.txt`、`01.chapters.txt` 或 `01.chap`），程序支持以下两种标准格式：

### 1. 标准 OGM 格式
```text
CHAPTER01=00:00:00.000
CHAPTER01NAME=01-课程导读与概要
CHAPTER02=00:02:30.500
CHAPTER02NAME=02-核心原理深度剖析
CHAPTER03=00:08:15.200
CHAPTER03NAME=03-动手实战与代码演练
CHAPTER04=00:15:40.000
CHAPTER04NAME=04-课程回顾与课后答疑
```

### 2. 简易时间戳格式（推荐，易于手动编辑）
```text
00:00:00 精彩开场与课程介绍
00:02:30.500 第一部分：环境配置
00:08:15 第二部分：核心逻辑实战
00:15:40 总结回顾与下期预告
```
> 时间戳支持以空格、横杠（`-`）或冒号（`:`）作为分隔符。

## 三、快速使用方法

### 方式 1：双击运行图形界面 (推荐)
直接双击运行目录下的：
```text
启动章节注入工具.bat
```
或直接双击便携包内的 `MP4ChapterTool.exe`，也可以在终端执行：
```bash
python mp4_chapter_tool.py
```

**操作指南：**
1. **选择目录**：点击 **【浏览文件夹...】** 选择视频所在目录（默认自动加载当前目录）。
2. **递归选项**：勾选 **【☑ 搜索子目录(递归包含子文件夹)】** 可智能深度检索各层子目录。
3. **列表浏览与右键**：列表中会清晰呈现视频相对路径、就绪状态、匹配的文本及检测到的章节数。
   - 在列表条目上**单击右键**，可弹出快捷菜单：`▶ 播放选中的视频`、`📂 打开视频所在文件夹`、`📝 查看/编辑章节文本`、`🚀 仅注入此视频`。
4. **生成样例体验**：点击 **【✨ 自动生成样例】** 即可一键生成测试视频与章节文本。
5. **开始注入**：点击 **【🚀 一键批量注入章节】** 开始秒级注入。
   - 默认模式：注入到原目录下的 `with_chapters/` 子文件夹（保持完整子目录树）。
   - 勾选 **【覆盖原视频】**：原地覆盖并自动保留 `.bak` 备份文件。
6. **校验与播放**：双击列表中的视频或点击 **【▶ 播放选中视频】** 直接调出系统默认播放器检验效果。
7. **查看关于**：点击 **【ℹ 关于】** 或菜单栏 **【帮助 -> 关于】** 查阅功能特性与联系支持。

---

### 方式 2：命令行调用 (适合自动化脚本)

```bash
# 1. 扫描指定目录并注入到 with_chapters/ 目录
python mp4_chapter_tool.py --cli --dir "D:/视频目录"

# 2. 递归扫描包含所有子目录，输出时保持各子目录相对层级
python mp4_chapter_tool.py --cli --dir "D:/视频目录" -r

# 3. 指定自定义输出目录
python mp4_chapter_tool.py --cli --dir "D:/视频目录" -r --output "E:/成品输出"

# 4. 直接覆盖原视频（会自动备份为 .bak 文件）
python mp4_chapter_tool.py --cli --dir "D:/视频目录" --overwrite

# 5. 自动生成演示样例并处理
python mp4_chapter_tool.py --cli --dir "D:/测试目录" --generate-sample
```

**命令行参数一览：**
| 参数 | 缩写 | 作用说明 |
| :--- | :--- | :--- |
| `--dir` | `-d` | 目标视频所在目录路径 |
| `--output` | `-o` | 成品视频输出目录（默认为目标目录下的 `with_chapters/`） |
| `--recursive` | `-r` | 开启子目录递归深度扫描 |
| `--overwrite` | | 直接覆盖原视频（自动保留同目录下 `.bak` 备份） |
| `--generate-sample` | | 在目标目录自动生成演示视频与配套章节文本 |
| `--cli` | | 强制以纯命令行终端模式运行 |

## 四、在播放器中的交互与章节跳转

章节成功注入后，即可在主流播放器中享受交互式章节选集体验：

### 1. PotPlayer 播放器
- **快捷键**：在播放画面中按下字母 **`H`** 键，右侧即可弹出 **【章节/书签】** 抽屉栏，点击任意章节名称即刻无缝跳播。
- **进度条标记**：播放器进度条上会自动显示章节分割断点，鼠标悬停时会浮动显示该章节的标题名称。
- **右键菜单**：右键画面 -> **【播放】** -> **【章节/书签】** -> 选择对应章节。
- **上一章/下一章**：快捷键 `[` (上一章节) 与 `]` (下一章节)。

### 2. VLC 播放器
- **顶部菜单**：点击顶部菜单栏中的 **【播放 (Playback)】** -> **【章节 (Chapter)】**，可在下拉菜单中直接选择章节。
- **上一章/下一章**：快捷键 `Shift + P` / `Shift + N`。
- **进度条提示**：鼠标滑过进度条可以看到各个章节的分界标记。

### 3. IINA (macOS) / 其它现代播放器
- 在侧边栏“章节”列表面板中即可查阅所有带时间戳的章节大纲，点击即可精准定位。

## 五、项目文件清单

- `mp4_chapter_tool.py`: 核心程序，整合无损注入引擎、子目录递归扫描、现代 GUI 界面与 CLI 模式。
- `chapter_parser.py`: 章节解析引擎，支持 OGM 与简易时间戳格式，转换标准 FFMETADATA，自动探测视频时长。
- `generate_samples.py`: 样例生成器，生成带有动态测试卡、色彩渐变、测试音轨与章节文本的测试套件。
- `build_portable.py`: Windows 便携发布包组装脚本。
- `启动章节注入工具.bat`: Windows 便捷启动脚本。
- `使用说明.txt`: 本地纯文本便携使用说明文档。

### 关于 ffmpeg / ffprobe 的获取

仓库提交的代码**不包含** `ffmpeg.exe` / `ffprobe.exe`（二者单文件均超过 100MB，超出 GitHub 单个文件 100MB 上传上限，故不纳入仓库）。请按以下任一方式获取：

1. **gyan.dev 官方构建版（推荐）**：访问 <https://www.gyan.dev/ffmpeg/builds/> 下载 `ffmpeg-release-full.7z`，解压后取出 `ffmpeg.exe` 与 `ffprobe.exe`。
2. **BtbN GitHub Releases 构建**：访问 <https://github.com/BtbN/FFmpeg-Builds/releases> 下载 `ffmpeg-master-latest-win64-gpl.zip`，解压后取出 `ffmpeg.exe` 与 `ffprobe.exe`。

**使用方法**：将 `ffmpeg.exe` 与 `ffprobe.exe` 放入本程序所在目录即可——程序会自动优先调用同目录下的 `ffmpeg.exe`；也可将二者所在目录加入系统 `PATH`。放入程序目录后，直接双击 `启动章节注入工具.bat` 即可使用，无需额外配置。

> 提示：建议两个文件取自同一套官方稳定构建，并保持 64 位 Windows 版本。

## 六、常见问题解答 (FAQ)

**Q1：注入章节会降低我的视频画质吗？会重新压缩吗？**  
A：**绝对不会！** 工具使用 FFmpeg 流拷贝（`-c copy`）技术，本质上只是把章节元数据打包进 MP4 封装盒，视频轨与音频轨完全保持原始数据，一帧不改，无损且处理极快。

**Q2：章节文本的中文在播放器中显示乱码怎么办？**  
A：本工具内置智能编码探测，无论文本保存为 UTF-8、带有 BOM 的 UTF-8 还是 Windows 记事本默认的 GBK/ANSI，程序均能自动识别，从根源杜绝乱码。

**Q3：为什么有些视频扫描出来显示“未找到同名txt”？**  
A：请确认章节文本与视频主文件名完全一致（如 `demo.mp4` 必须对应 `demo.txt`、`demo.chapters.txt` 等），且两者存放在同一个文件夹中。

**Q4：便携版可以在其它没有安装 Python 或 FFmpeg 的电脑上运行吗？**  
A：完全可以！便携版已内置所有必要组件，解压到任何 64 位 Windows 电脑甚至 U 盘上即可随开随用。
