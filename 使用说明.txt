================================================================
          MP4 章节信息批量注入工具 (MP4 Chapter Injector)
                          便携使用说明
================================================================

【这是什么】
  本工具用于将指定文件夹及多层子目录下的 MP4 / M4V / MOV 视频与同名
  章节文本文件自动匹配，并将章节信息无损高速注入视频文件中。
  注入后可在 PotPlayer、VLC 等主流播放器中调出章节列表与进度条断点。

  * 无损流拷贝：采用 FFmpeg -c copy 技术，不重新编解码音视频，原画质与音质 100% 保持不变。
  * 秒级完成：数 GB 的大视频通常几秒钟内即可完成章节写入。

----------------------------------------------------------------
【文件清单】
  * MP4ChapterTool.exe       图形界面版（双击运行，推荐）
  * MP4ChapterTool-CLI.exe   命令行版（适合脚本批处理 / 自动化任务）
  * 使用说明.txt             本说明文件

----------------------------------------------------------------
【获取 ffmpeg / ffprobe】（程序运行必需，本包未内置）
  本工具依赖 FFmpeg 音视频组件，因文件体积超 GitHub 单文件上传上限，
  不随包内置。请从以下任一官方渠道下载后，将 ffmpeg.exe 与 ffprobe.exe
  放入本程序所在目录（程序会自动优先调用同目录下的 ffmpeg.exe，
  找不到时改用系统 PATH 中的 ffmpeg）：

  1. gyan.dev 官方构建版（推荐）：https://www.gyan.dev/ffmpeg/builds/
     下载 ffmpeg-release-full.7z，解压后取出 ffmpeg.exe 与 ffprobe.exe。
  2. BtbN GitHub Releases 构建：https://github.com/BtbN/FFmpeg-Builds/releases
     下载 ffmpeg-master-latest-win64-gpl.zip，解压后取出 ffmpeg.exe 与 ffprobe.exe。

----------------------------------------------------------------
【图形界面 (GUI) 操作步骤】
  1. 双击运行 MP4ChapterTool.exe。
  2. 点击【浏览文件夹...】选择存放视频和章节文本的目录。
  3. 勾选【搜索子目录(递归)】：
     * 勾选时（默认）：深度遍历所有下级子文件夹，自动匹配各子目录内的视频与同级文本。
     * 未勾选时：仅扫描当前第一级目录。
  4. 列表操作与右键快捷菜单：
     * 列表中会直观显示文件相对路径、就绪状态及解析出的章节数。
     * 在条目上【单击右键】可呼出快捷菜单：播放视频、打开所在目录、查看/编辑章节文件。
  5. 点击【🚀 一键批量注入章节】：
     * 默认模式：注入至视频目录下的 with_chapters/ 文件夹中（自动镜像完整子目录结构，杜绝同名覆盖）。
     * 勾选【覆盖原视频】：直接覆盖原文件，原视频会自动重命名为 .bak 作为安全备份。
  6. 校验播放：双击条目或点击【▶ 播放选中视频】，调出播放器检验章节跳转效果。
  7. 关于与支持：点击工具栏【ℹ 关于】或菜单栏【帮助 -> 关于】查看详情。

----------------------------------------------------------------
【支持的章节文本格式】（文本文件名需与视频同名，如 video1.mp4 对应 video1.txt）
  
  格式一：标准 OGM 格式
  ------------------------------------------------
  CHAPTER01=00:00:00.000
  CHAPTER01NAME=01-课程概要与引言
  CHAPTER02=00:02:30.500
  CHAPTER02NAME=02-核心原理深入
  CHAPTER03=00:08:15.200
  CHAPTER03NAME=03-代码动手实战
  CHAPTER04=00:15:40.000
  CHAPTER04NAME=04-总结与下期预告

  格式二：简易时间戳格式（推荐，易于手工记录）
  ------------------------------------------------
  00:00:00 开场与课程介绍
  00:02:30.500 第一部分：环境配置
  00:08:15 第二部分：核心实战
  00:15:40 总结致谢

  * 编码支持：原生自动识别 UTF-8、带有 BOM 的 UTF-8、GBK、GB18030 等中文编码，杜绝乱码。

----------------------------------------------------------------
【命令行 (CLI) 常用指令】
  :: 为目录下所有视频注入章节（输出到 with_chapters/）
  MP4ChapterTool-CLI.exe --dir "D:\视频目录"

  :: 递归扫描所有子目录并注入（保持相对层级）
  MP4ChapterTool-CLI.exe --dir "D:\视频目录" -r

  :: 指定自定义输出目录
  MP4ChapterTool-CLI.exe --dir "D:\视频目录" -r --output "E:\成品目录"

  :: 覆盖原视频（自动生成 .bak 备份）
  MP4ChapterTool-CLI.exe --dir "D:\视频目录" --overwrite

  :: 生成演示样例视频与章节文件（测试体验用）
  MP4ChapterTool-CLI.exe --dir "D:\测试目录" --generate-sample

----------------------------------------------------------------
【主流播放器章节跳转方式】
  1. PotPlayer 播放器：
     * 按快捷键【H】：在画面右侧直接弹出【章节/书签】列表，点击即可秒级跳转。
     * 进度条断点：鼠标悬浮在进度条的断点标记上，可查看章节名称。
     * 上一章/下一章快捷键：键盘【 [ 】与【 ] 】键。

  2. VLC 播放器：
     * 顶部菜单栏：点击【播放 (Playback)】->【章节 (Chapter)】直接点选。
     * 上一章/下一章快捷键：Shift + P / Shift + N。

----------------------------------------------------------------
【常见问题与注意】
  * 首次运行若弹出 Windows SmartScreen 提示，点击“更多信息”->“仍要运行”即可。
  * 本便携包已完整打包 FFmpeg，拷贝到任何 Win10/Win11 64位电脑均可即开即用。
